Sono scaricabili da [https://tdor.translivesmatter.info/](https://tdor.translivesmatter.info/). 
Nella cartella NUDM sono presenti invece i dati raccolti in 
[https://osservatorionazionale.nonunadimeno.net/](https://osservatorionazionale.nonunadimeno.net/)
e sono dati solo italiani.
